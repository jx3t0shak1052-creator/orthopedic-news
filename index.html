📱 端末の引っ越し（トークン不要）

学会の参加／不参加／未定・メモ・お気に入りを1つのコードにまとめます。新しい端末で貼り付けるだけで復元できます。サーバーもトークンも不要です。

URLとQRには学会ステータス・メモ・お気に入りだけを載せています（手動論文はサイズが大きいため「ファイル保存」に含まれます）。

上級者向け：GitHubに自動保存（トークン使用）

手動で追加した論文も含めて、変更のたびにGitHubへ自動保存します。トークンはこの端末のブラウザ内にのみ保存され、リポジトリには書き込まれません。

トークン作成：GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → リポジトリ orthopedic-news のみ → 権限 Contents: Read and write。
